# Aida Proposal Design

Crie uma landing page de proposta comercial em português (pt-BR), de altíssimo nível visual e profissional — deve parecer feita por um estúdio de design premium, não um template genérico de IA. Página única (one-page), sem necessidade de rotas.

CONTEXTO E OBJETIVO:
Esta é uma proposta de consultoria de marketing/social media enviada para uma fotógrafa profissional especializada em fotografia de família, gestante e infância, chamada Aida. Ela tem 7 anos de experiência. O objetivo da página é transmitir confiança, sensibilidade e profissionalismo, gerar identificação emocional e levá-la a agendar uma reunião.

TOM E ESTILO VISUAL:
- Estética editorial, quente e sofisticada — inspire-se em portfólios de fotografia premium e estúdios de branding boutique
- Paleta: tons terrosos e quentes (terracota, blush, bege, marfim), nada de cores corporativas frias
- Tipografia: serifada elegante para títulos (estilo editorial/revista), sans-serif limpa para corpo de texto
- Bastante espaço em branco, respiro entre seções, nada de excesso de elementos
- Micro-animações sutis ao rolar a página (fade-in suave), sem exageros
- Deve parecer artesanal e pensado especificamente para ela — evite qualquer elemento que pareça "proposta genérica de agência"
